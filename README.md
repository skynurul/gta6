**Solmar Bay** is a 2D top-down open-world crime game. Leo Marín, a broke courier, comes home to the coastal city of Solmar Bay with $40 in his pocket and a debt to the Harbor Crew. Drive and steal cars, outrun the Solmar Bay PD as your wanted level rises, and work through 5 story missions — from First Wheels to King of the Bay. Includes a HUD with cash, health, and wanted stars, a live minimap, and save support so you can pick up where you left off.

## Run it

```sh
python3 -m http.server --directory game
```

Then open http://localhost:8000 in desktop Chrome (or serve the `game/` directory with any static server, e.g. `npx serve game`). No build step, no network needed — the game runs fully offline.
